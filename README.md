# TNC Ride — เริ่มใหม่จากไฟล์ต้นแบบ

ใช้โครงสร้างและหน้าตาจากไฟล์ HTML ที่แนบในวันที่ 4 ต.ค. 2026 เปลี่ยนส่วนเก็บข้อมูลจาก Google Sheets/localStorage เป็น Supabase

## ใช้ Supabase Project URL เดิมได้
1. เปิดโปรเจกต์ Supabase เดิม > SQL Editor > New query
2. คัดลอก supabase/setup.sql ทั้งไฟล์ แล้ว Run หนึ่งครั้ง
3. จะสร้างตาราง tnc2_profiles, tnc2_trips, tnc2_passengers และฟังก์ชัน tnc2_* แยกจากตาราง tnc_* เดิม ไม่ลบหรือย้ายข้อมูลเก่า
4. สมาชิกในระบบชุดใหม่ต้องสมัครใหม่ เพราะยังไม่ย้ายข้อมูลสมาชิกเดิม

## Vercel
ใช้ Other, Build Command npm run build, Output Directory dist, Root Directory โฟลเดอร์ที่มี package.json
ตั้ง Environment Variables สำหรับ Production:
- SUPABASE_URL: Project URL เดิม https://…supabase.co ไม่มี /rest/v1/
- SUPABASE_SERVICE_ROLE_KEY: secret key หรือ service_role ของโปรเจกต์เดียวกัน เก็บเฉพาะฝั่ง server
- SESSION_SECRET: รหัสสุ่มอย่างน้อย 32 ตัวอักษร
ใช้ค่าที่ถูกต้องจาก Vercel เดิมได้ ไม่ต้องส่งกุญแจในแชต ไม่ใส่กุญแจในไฟล์ที่ Commit
ไม่ต้องตั้ง Google Apps Script, SMTP, Google Maps หรือ ADMIN_SETTINGS_SECRET สำหรับชุดนี้
Deploy โค้ดชุดนี้แล้วให้ตรวจชื่อ repository/branch ที่ Production ใช้ ก่อนทดสอบ

## พฤติกรรมตามต้นแบบ
สมัครด้วยชื่อและเบอร์โทร ไม่ส่ง OTP ไม่มีช่องอีเมลในต้นแบบนี้
เข้าสู่ระบบด้วยเบอร์โทรเท่านั้น คนที่ทราบเบอร์ของสมาชิกจึงสามารถเข้าแทนได้ เป็นข้อจำกัดของวิธีนี้
ชื่อและจุดรับส่งรองรับภาษาไทย/อังกฤษ แผนที่ Leaflet เดิม เลือกหมุดบนแผนที่ ไม่มี Google Embed หรือช่องตั้งน้ำมัน
ผู้ขับประกาศ ผู้โดยสารร่วมรถ ที่นั่งตรวจซ้ำและล็อกแถวในฐานข้อมูล ป้องกันแย่งที่นั่งสุดท้าย
เริ่ม/จบเที่ยวได้เฉพาะเจ้าของโดยตรวจรหัสสมาชิกฝั่งเซิร์ฟเวอร์
สำเร็จต่อเมื่อฐานข้อมูลตอบสำเร็จ ไม่บันทึกเที่ยวปลอมลง localStorage
History และสูตรในต้นแบบยังเป็นระยะเส้นตรง × 0.21 เป็นค่าประมาณ ไม่ใช่เครดิตที่รับรอง

## ทดสอบหลัง Deploy
สมัครสมาชิกสองคนในคนละเบราว์เซอร์ > คนแรกประกาศ 1 ที่นั่ง > คนที่สองเข้าร่วม > ตรวจเต็มและรายชื่อ > เจ้าของเริ่ม/จบ > ตรวจ History > Refresh แล้วยังอยู่
ตรวจ Supabase Table Editor ที่ตาราง tnc2_* เพื่อยืนยันว่าบันทึกจริง
โค้ดถูกทดสอบในเครื่อง แต่ยังไม่ได้รัน SQL หรือบันทึกข้อมูลจริงใน Supabase ของคุณ
